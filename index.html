About the project

QR Sign-In is a simple attendance system for students, teachers, and event organizers. Instead of writing names on a paper sheet, participants will be able to scan a code and enter their details.

How it works

1

Create a session

The organizer creates a class or event sign-in.

2

Scan the code

Participants scan the QR code with their phone.

3

Record attendance

Their sign-in is added to the attendance list.
