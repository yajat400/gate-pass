# QR Sign-In System

A beginner-friendly static website concept for a QR-based class and event attendance system.

## Files
- `index.html` — main webpage
- `style.css` — page styling and responsive layout

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish and copy the URL shown on the Pages settings screen.

Note: This is currently a static project draft. The QR graphic is a placeholder; scanning and attendance recording are not implemented.
